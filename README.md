## Project Workflow

### 1. Data Loading

* Import dataset into Python.
* Read data using Pandas.
* Verify data structure and column types.

### 2. Exploratory Data Analysis (EDA)

* Check dataset shape.
* Analyze summary statistics.
* Identify trends and distributions.
* Detect missing values and outliers.
* Create visualizations.

### 3. Data Cleaning

* Handle missing values.
* Remove duplicate records.
* Correct data types.
* Standardize column names.
* Treat outliers where necessary.

### 4. SQL Analysis

* Import cleaned data into PostgreSQL/MySQL/SQL Server.
* Write SQL queries for:

  * Filtering
  * Sorting
  * Aggregation
  * GROUP BY
  * JOINs
  * Window Functions
  * Business KPIs

### 5. Power BI Dashboard

Develop an interactive dashboard containing:

* KPI Cards
* Sales Trends
* Category Analysis
* Regional Performance
* Filters/Slicers
* Charts and Visualizations

### 6. Reporting

Prepare a professional report summarizing:

* Business Objective
* Data Cleaning Process
* Analysis
* Key Insights
* Recommendations

### 7. Presentation

Create a concise PowerPoint presentation using Gamma that includes:

* Project Overview
* Dataset
* Methodology
* Dashboard Screenshots
* Key Findings
* Business Recommendations

## How to Run

1. Clone the repository.
2. Install the required Python libraries:

   ```bash
   pip install -r requirements.txt
   ```
3. Place the dataset in the `data/` folder.
4. Run the Python notebook or script to perform EDA and data cleaning.
5. Import the cleaned dataset into PostgreSQL, MySQL, or SQL Server.
6. Execute the SQL queries in the `sql/` folder.
7. Open the Power BI file (`.pbix`) to explore the dashboard.
8. Review the project report and presentation for a summary of insights.
